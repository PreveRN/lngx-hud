## COMMANDS & KEYBINDS

| Command | Keybind | Description |
| :--- | :---: | :--- |
| `/hud` | <kbd> - </kbd> | Open HUD settings menu |
| `/vehmenu` | <kbd> - </kbd> | Open vehicle control menu |
| `/seatbelt` | <kbd>B</kbd> | Toggle vehicle seatbelt |
| `/cruise` | <kbd>CAPSLOCK</kbd> | Limit Km/h  |

## SUPPORTED FRAMEWORKS

* **ESX** (`es_extended`)
* **QBCore** (`qb-core`)
* **Qbox** (`qbx_core`)
